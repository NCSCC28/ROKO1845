1. Project Overview
ROKO (Realm of Knowledge and Oneness) is a multi-religious spiritual application providing access to sacred texts from Bhagavad Gita, Bible, and Quran. Built with React/TypeScript frontend and Supabase backend, featuring AI chatbot, semantic search, quiz system, favorites, notes, speech synthesis, and voice recognition. Supports multiple languages (English, Hindi, Telugu, Arabic) with dark/light theme.

2. System Architecture
Frontend (React/TypeScript/Vite) → Backend (Supabase) → Database (PostgreSQL) → External APIs (OpenRouter, Dialogflow)

4. Use Case Diagram Data
Actors: User, Admin, System
Use Cases:
- User: View daily verse, Browse Gita/Bible/Quran, Search verses, Listen to audio, Save favorites, Take quiz, Chat with AI, Add notes, Toggle theme
- Admin: Manage content (not implemented in current code)
- System: Generate daily verse, Process AI responses, Handle speech synthesis, Store user data

5. Sequence Diagram Data
User opens app:
1. App loads → ThemeProvider initializes
2. Navbar renders with tabs
3. HomePage loads → fetches daily verse from daily_verses table
4. Display verse with audio option

User searches Gita:
1. GitaPage loads → fetches all verses from gita_verses table
2. User enters search → filter verses locally
3. User selects verse → display with translations
4. User clicks speak → useSpeech synthesizes audio

AI chatbot interaction:
1. User opens RokoAssistant
2. User types message → intentHandler processes
3. If spiritual query → generateDialogflowReply or generateLocalAiReply
4. Display response with scripture reference

Database queries:
1. Component calls supabase.from('table').select()
2. Supabase processes query with RLS policies
3. Returns data → component updates state

6. Activity Diagram Data
User opens app → Check theme preference → Load HomePage → Fetch daily verse from database → Display verse → User selects feature

If Gita: Load GitaPage → Fetch verses → User searches/filters → Select verse → Optional: Generate Telugu explanation → Optional: Speak verse → Optional: Add to favorites

If AI Chat: Open RokoAssistant → User inputs message → Detect intent → If verse reference: Fetch from database → If general: Call AI API → Display response

If Quiz: Load QuizPage → Fetch questions → User answers → Calculate score → Save result

All activities can loop back to home or continue to other features. Database operations run in background with loading states.

7. Deployment Diagram Data

External APIs: OpenRouter (AI), Dialogflow (NLP)
